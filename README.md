# 🧠 快快长脑子

给 12 岁小朋友的克莱因蓝脑力乐园。纯静态网站，无框架、无依赖、无广告、无追踪。

在线地址：<https://zhangnaozi119.github.io>

## 四大模块

| 模块 | 页面 | 内容 |
| --- | --- | --- |
| 🎮 游戏长脑子 | `games.html` | 记忆翻牌、舒尔特方格、24 点、反应力测试 |
| 📚 学习长脑子 | `learn.html` | 60 秒速算挑战、冷知识翻转卡片、10 题知识闯关 |
| 😂 笑话长脑子 | `jokes.html` | 脑筋急转弯、冷笑话、谐音梗、科学冷幽默 |
| 🧩 长脑子好玩 | `play.html` | 汉诺塔、视错觉实验室、8 道经典思维谜题 |

## 设计

主色为国际克莱因蓝 **IKB #002FA7**，辅以明黄 `#FFD400`、薄荷绿 `#17C3A2`、珊瑚红 `#FF5A5F`。
全站响应式，手机 / 平板 / 电脑均可使用。

## 目录结构

```
.
├── index.html          首页（含每日一题）
├── games.html          游戏长脑子
├── learn.html          学习长脑子
├── jokes.html          笑话长脑子
├── play.html           长脑子好玩
├── assets/
│   ├── css/style.css   全站设计系统
│   └── js/
│       ├── main.js     导航 / Tab / 本地存储 / 工具函数
│       ├── games.js    四个游戏
│       ├── play.js     汉诺塔 + 视错觉 + 谜题
│       ├── jokes.js    笑话数据与渲染
│       └── learn.js    速算 + 卡片 + 闯关
└── .nojekyll           关闭 GitHub Pages 的 Jekyll 处理
```

## 本地预览

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```

## 数据说明

所有成绩记录（最少步数、最快时间、最高分）都通过 `localStorage` 存在浏览器本地，
不上传、不联网、不收集任何信息。换个浏览器就会重新开始。
